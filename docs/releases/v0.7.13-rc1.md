# v0.7.13-rc1 — 기반 정리·공격수 승계·판정 기록 (소스 전용 사전 배포)

작성일: **2026-10-29**. 이 버전은 [keymaker7 포크](https://github.com/keymaker7/Drone-Soccer-Simulator)의 **소스 전용 사전 배포**다. **Windows 실행 ZIP은 포함하지 않는다.** 이 변경을 만든 PC에는 Unreal Engine 5.8이 없어 Editor·Shipping 빌드, 패키지 실행, 새 경로 ZIP 검사를 수행하지 못했다. 실행할 사람은 원본의 [v0.7.12-rc1 실행 ZIP](https://github.com/sun475300-sudo/Drone-Soccer-Simulator/releases/tag/v0.7.12-rc1)을 사용한다. 그 ZIP에는 아래 변경이 들어 있지 않다.

기준은 원본 `v0.7.12-rc1` 태그(`df358d8`)와 원본 `main`의 이후 문서 변경이다. 진행 중인 `codex/topgun-training`은 포함하지 않는다.

## 이번 변경

- **릴리스 소스를 main에 병합:** 원본 `main`에는 v0.7.12-rc1 이후 문서 커밋만 있어 공개된 소스가 빠져 있었다. `Source`·`Tests`·`Bridge`·`Scripts`·`Config`·`Content`를 태그와 같게 맞췄다.
- **GitHub Actions CI:** 엔진 없는 MSVC 테스트 9개(규칙·조종기 보정·물리·자율 유도·수동 스로틀·조종 응답·AI 훈련/공격수/복구), Python 테스트(보호구 형상·비행 기록 분석·고정 upstream 커밋의 SDACS 연동), 저장소 위생 검사를 PR과 main마다 실행한다.
- **공격수 승계(RUL-08, 규칙 코어):** 득점 자격을 고정 ID 0·5 대신 팀별 현재 공격수로 판정한다. `ConfirmStrikerSuccession(team)`은 심판 확인만 기록하며 단순 충돌로 호출하지 않는다. 자세한 조건은 [규정 근거](../rules-sources-2026.md#구현과-검증)에 있다.
- **판정 사건 기록(규칙 코어):** 득점·역방향 통과·오프사이드 중 공격 페널티·자기 골대 역진입 페널티·오프사이드 해제·공격수 승계·세트 종료를 시각·세트·남은 시간·점수와 함께 기록한다. 최근 1,024개를 보관한다.

## 아직 연결하지 않은 것

공격수 승계와 판정 기록은 **엔진 독립 규칙 코어까지만** 구현했다. 게임 화면에서 쓰려면 아래 Unreal 작업이 필요하며, UE 5.8 PC에서 빌드·실행 검사를 거쳐야 한다.

- 심판 승계 입력(HUD 버튼·키), 역할 이름·하단 띠·LED 전환, AI 공격수 선택
- 판정 기록의 F6 JSONL·CSV 내보내기와 HUD 표시, 심판 취소·정정 이력

기본 공격수가 기존과 같은 0·5이고 공개 API는 추가만 했으므로, 기존 Unreal 호출부의 동작은 바뀌지 않도록 설계했다. 다만 **Unreal 컴파일과 실행은 확인하지 않았다.**
