# v0.5.0 — Windows integrated build

2026-10-26 KST. This release publishes the verified Windows package together with
its corresponding project source. It is a Development Win64 package; it does not
require Unreal Editor to run. Source development uses Unreal Engine5.8.

## Included

- All ten aircraft use ANGLE manual control with neutral-stick levelling.
- Both Strikers start at the centre of their own start line, y=0, x=±6.5m.
- Pilot-relative lanes: Libero,Guide,Striker,Sweeper,Keeper. Actual pads,reset
  locations,homes and LOS stations share the same layout.
- Striker green and Guide pink lower ribbons: two per side,four per aircraft.
- Separate team/role/front/rear LED markings and existing S/G tags.
- Balanced/High/Cinematic controls, restrained bloom/sharpening, broad fill light,
  contact-driven floor dust and thrust-driven near-floor dust.
- Configurable build/launch paths and a source-fingerprint check for local builds.

## Running

Download the Windows ZIP,extract the entire directory and run
`ImperialWingsSimulator.exe`. Keep the adjacent Engine and project directories.
Startup uses keyboard input and disarmed motors. Choose and calibrate your own
USB device before explicitly enabling USB input. No personal radio profiles,
machine-local paths,environments,logs or debug symbols are distributed.

The standalone download supports local manual play. Autonomous Practice requires
the separately configured SDACS bridge from the source project. Its background
startup was blocked by execution policy during final verification,so automatic
connection is not included in this release's verification claims.

or collision and are not cloth or detachment simulations. The cosmetic pool test
uses explicit synthetic bursts; it is separate from actual flight/contact tests.
