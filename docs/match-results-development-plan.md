# 드론축구 64개 대진 기록 분석과 시뮬레이터 개발 계획

분석일: 2026-10-26 KST. 기존 프로젝트는 수정하지 않았다.

## 분석 범위와 방법

2025년 상하이 FAI 세계드론축구선수권 F9A-A(40cm, 5대5) 공식 결과표의 조별리그 64개 대진 행을 전사·검산했다. A조 20건, B조 20건, C조 12건, D조 12건이다. 같은 상대의 1차·2차 라운드는 별도 대진으로 세며 세트 하나를 경기 여러 개로 부풀리지 않았다. 자체 ID A01~D12는 원문 대진 행 순서다. 원문 PDF 6~9페이지와 CSV를 대조할 수 있다.

이 자료는 단일 대회의 결과표 분석이다. 50개 이상 경기 영상의 프레임별 관찰, 포지션 궤적, 충돌 빈도, 공격 경로, 반환 시간은 분석하지 않았다. FAI 결과를 FIDA 규칙의 근거로 취급하지 않는다.

## 자료 품질

- C05: UZB-A1–SIN-A1. DNF, 발표 결과 2–0, 기재 득점 4–60. 사유를 추정하거나 결과를 임의로 수정하지 않는다.
- C11: SIN-A1–UZB-A1. DNF, 발표 결과 1–0, 득점 공란.
- A08: HKG-A1–JPN-A1. 발표 세트 결과 2–1, 개별 세트 14–3/9–7/20–11로 추출되어 불일치한다.
- B04: TPE-A1–MAS-A1. 발표 세트 결과 2–1, 개별 세트 15–4/16–10/17–14로 추출되어 불일치한다.
- 위 4건은 통계에서 제외한다. 두 불일치는 원본 표의 텍스트 추출과 검산에서 발견한 미해결 항목이며 공식 정정으로 주장하지 않는다. 원문 시각 재확인·주최 측 확인이 필요하다.
- 최종 통계 모집단: 60대진, 118세트(1차 29대진×3세트, 2차 31대진×1세트).

## 계산 결과

- 세트별 양 팀 합계 득점 총합 3,148, 세트당 평균 26.68.
- 한 팀의 세트 득점 최댓값 46.
- 세트 무승부 1건, 1골 차 6건, 3골 차 이하 17건(무승부 포함).
- D01 AUS-A1–TUR-A1: 합계 36–32, 세트 1–2. 총득점 우세 팀 패배.
- D05 CHN-A1–AUS-A1: 합계 24–26, 세트 2–1. 총득점 열세 팀 승리.
- 결과표에서 1차 라운드는 3세트, 2차는 1세트로 기록된다. 1차에는 3–0 결과가 있어 항상 2승 시 즉시 끝나는 형식으로 볼 수 없다.
- 서로 다른 형식을 합친 평균은 기술 통계일 뿐이다. 1차·2차의 실력 변화나 전술 효과를 이 평균으로 추정하지 않는다.
- 득점별 시각·정규시간과 페널티 득점 분리가 없어 초당 득점, 평균 공격 주기와 귀환 시간을 역산하지 않는다.
- 한 대회·한 클래스 표본이므로 모든 드론축구 경기의 대표 표본으로 취급하지 않는다.

## 경기 방식 설계

현재 프로젝트의 기본은 FIDA 2026 Class40으로 유지한다. FAI 2025 대회 재현은 별도 프로필로 작성하고 경기장·골대·출발·LED·페널티·승패 판정 전체를 해당 판본에 맞춘 뒤 제공한다. 단지 세트 수만 바꾼 상태를 FAI 공식 모드로 표시하지 않는다.

권장 경기 흐름: 규정 프로필 선택 → 팀/선수/기체 등록 → 기체·입력 사전 확인 → 진영 결정 → 역할별 시작 위치 → 준비 신호 → 수동 경기 → 득점/귀환/위반 사건 기록 → 세트 종료 → 해당 프로필의 페널티·검토·결과 확정 → 정비·교체 → 다음 세트 또는 최종 결과.

공통 경기 상태에는 Ready, Playing, Suspended, SetReview, Penalty, Maintenance, Finished를 두되 순서·허용 조작은 규정별로 정의한다. ARM 허용 시점도 프로필과 실제 준비 절차에 맞춰 검증한다. 네트워크 연결 여부가 심판의 경기 시계·판정을 바꾸지 않도록 한다.

## 구현할 작업과 완료 기준

### 1차: 데이터와 경기 결과 코어 — P0
- [ ] MatchFormat에 세트 수, 세트 시간, 조기 종료 여부, 동점 정책, 정비시간, 경기 단계별 예외를 명시한다.
- [ ] FIDA2026Class40, FAI2025WDSC, CustomPractice를 식별하고 판본·출처를 저장한다.
- [ ] 현재 세트 득점, 세트별 승무패, 최종 경기 승패, 대회 순위용 누적 득점을 분리한다.
- [ ] 총득점으로 경기 승자를 정하지 않도록 D01/D05를 회귀 시험으로 사용한다.
- [ ] 3세트 전부 진행과 2승 선취 종료, 단일 세트 형식을 각각 시험한다.
- [ ] 16–16 무승부 세트, 1골 차 세트, 46골을 표시·저장·불러오기 한다.
- [ ] DNF·몰수·불참·경기 중단·자료 오류를 별도 상태와 사유로 관리한다.
- [ ] 원문 결과, 자동 계산 결과, 심판 확정 결과를 별도 보관하고 정정 이력을 남긴다.
완료: 60개 일관된 대진으로 세트 결과를 재계산할 수 있고 나머지 4개를 자동 탐지·격리한다. 이는 경기 결과 코어 시험이며 실제 물리 궤적 재현 시험이 아니다.

### 2차: 수동 경기와 심판 운영 — P0
- [ ] Boxer 물리 채널·방향·중립·최저 스로틀과 실제 수동 비행을 검증한다.
- [ ] 기체 ID에 고정된 공격수 권한을 팀별 역할 상태로 교체한다.
- [ ] FIDA 공격수 철수 선언 → 조종 중단 → Guide 접촉 → 심판 확인 → 역할 승계 절차를 구현한다.
- [ ] 역할 승계 시 LED·태그·명칭·득점 권한을 함께 갱신한다.
- [ ] 태그 탈락, 완전 통과, 반대 방향 진입, 오프사이드 상태를 각각 기록한다.
- [ ] 득점 이후 전원 복귀 여부를 선수별로 표시하고 철수 선언 기체를 구분한다.
- [ ] 심판용 중단·재개·득점 정정·위반·경고·철수 화면을 제공한다.
- [ ] FIDA 페널티는 세트 종료 뒤 Striker/Keeper 대결로 처리하고 시간·시작 위치·득점 권한을 별도로 둔다.
- [ ] FIDA 정비시간은 단순 종료 직후 자동 300초와 회수·퇴장 이후 기산을 구별한다.
- [ ] FIDA에서 1승2무 최종 승자, 동점 허용 여부, 연장·승부치기 정책을 시험한다.
완료: 정상 경기와 공격수 철수·페널티·중단 사례를 포함한 전 경기를 운영하고 판정 사유를 재검토할 수 있다.

### 3차: 포지션·LED·LOS 식별 — P1
- [ ] 시작선은 규정으로, 다섯 역할의 좌우 순서는 훈련용 설정으로 분리한다.
- [ ] 현재 팀별 거울 배치·초기 방향·홈 위치·조종자 위치의 일치를 시험한다.
- [ ] 역할색과 팀색, 숫자·태그를 함께 표시한다.
- [ ] 전방 한 줄·후방 두 줄 방향등을 양 팀 LOS 거리에서 판별한다.
- [ ] 빨강 팀과 빨간 후미등, 흰 Keeper와 흰 전방등의 혼동을 시험한다.
- [ ] 발광·노출·가림에 따라 색과 방향이 소실되지 않게 조정한다.
- [ ] 공격수 승계와 기체 교체 후 표시를 확인한다.
완료: 색·번호·형태로 팀·역할·방향을 구분하고, 추가 방향등을 공식 의무 규격이라고 표시하지 않는다.

### 4차: 훈련 시나리오와 전술 계측 — P1
다음 항목은 결과표에서 관찰한 전술이 아니라 규칙 기반 훈련 설계안이다.
- [ ] 첫 이륙·골대 접근·완전 통과·접촉 뒤 복구 훈련.
- [ ] 득점 → 마지막 선수 복귀 → 재공격의 반복 훈련.
- [ ] Guide 지원·수비 복귀·Keeper 차단·공격수 승계 훈련.
- [ ] 1골 차 리드·열세, 동점 세트·인원 감소 상황 훈련.
- [ ] 공격 시도·유효 통과·접촉·회복·중앙선 복귀 사건의 시각을 기록한다.
- [ ] 성공률, 복귀 지연 선수, 복귀 완료 시간, 반칙, 충돌 후 조종 회복 시간을 정의한다.
- [ ] 자율 기체는 Practice 보조로 구분하고 수동 경기 성적과 섞지 않는다.
완료: 각 훈련의 시작 조건·종료 조건·평가식이 있고 수동 조종으로 재현 가능하다.

### 5차: 전술 영상 분석 확대 — P1
- [ ] 완전한 경기 영상 50개 이상에 고유 ID, 대회, 규정, 클래스, 상대, 원본 URL을 부여한다.
- [ ] 현재 64개 대진 중 영상과 대조되는 경기만 연결하고 불확실한 연결은 비워 둔다.
- [ ] 시작·득점·귀환 완료·재공격·방어 접촉·철수·정비를 영상 시각으로 표기한다.
- [ ] 원근·가림으로 좌표를 확인할 수 없을 때 수치를 추정하지 않는다.
- [ ] 다중 시점이나 카메라 보정 없는 영상에서 정확한 3D 속도·거리를 주장하지 않는다.
- [ ] 경기 일부를 중복 판독해 관찰자 간 사건 시각·분류 일치도를 확인한다.
- [ ] 검증된 반복 패턴에 한해 훈련 시나리오와 AI 난이도로 반영한다.
완료: 50개 이상 서로 다른 경기 영상의 검토 구간과 사건 시각이 남는다. 이번 결과표 분석과 별도 성과다.

### 6차: 대회·기록·리플레이 — P1
- [ ] 조 편성·동일 상대 재대결·라운드별 형식·대진표를 지원한다.
- [ ] 조별리그와 토너먼트의 승점·순위·동점 정책을 프로필별로 정의한다.
- [ ] 심판 판정·세트 결과·누적 득점·DNF 사유를 내보낸다.
- [ ] 물리 상태와 입력·역할·판정 사건을 같은 시간축에 저장한다.
- [ ] 판정 검토 시점으로 이동하는 리플레이를 제공한다.
- [ ] 원본 공식 결과를 변경하지 않고 정정 기록을 추가한다.
완료: 대회 시작부터 최종 순위까지 일관된 결과가 생성되고 정정 근거를 추적한다.

### 7차: 물리·그래픽·성능 — P1
- [ ] 일정 주기 제어와 20~240FPS·지연 조건 비교.
- [ ] 전환 전 자율 요청의 늦은 응답 무시, 귀환 중 연결 손실 시험.
- [ ] 실기체 추력·배터리·관성·항력·접촉 자료로 계수 보정.
- [ ] 실제 경기 거리에서 기체·LED·골대·중앙선 가독성 우선 개선.
