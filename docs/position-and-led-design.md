# 포지션별 시작 패드와 식별 LED

확인·구현: 2026-10-26 KST. [FIDA Class40 규정](https://fidasystem.com/rules.html)의 시작선은 짧은 끝선에서1.5m 안쪽이며 선 또는5개 점으로 표시한다. 규정은 다섯 역할의 좌우 순서를 지정하지 않는다. 이 시뮬레이터는 각 팀 조종자가 보는 왼쪽부터1–5번으로 정렬하는 **훈련용 배치**를 선택했다. 페널티킥의 스트라이커 중앙선 출발을 일반 경기 시작 배치에 섞지 않았다.

| 번호·포지션 | 역할 LED·패드 | Blue 시작점(m) | Red 시작점(m) |
|---|---|---|---|
| 1 Striker | 초록·S 태그 | (-6.5,-2.5) | (6.5,2.5) |
| 2 Guide | 분홍·G 태그 | (-6.5,-1.25) | (6.5,1.25) |
| 3 Libero | 하늘색 | (-6.5,0) | (6.5,0) |
| 4 Sweeper | 노랑 | (-6.5,1.25) | (6.5,-1.25) |
| 5 Keeper | 흰색 | (-6.5,2.5) | (6.5,-2.5) |

좌표는 경기장 중심 기준이다. 모든 기체의 초기 몸체 전방은 중앙선을 향한다(Blue +X,Red -X). 역할색은 공식 기준이고,패드의 좌우 순서·글자·화살표는 훈련용 표시다. 패드는 충돌체 없는 바닥 표시이며 출발 장애물을 추가하지 않는다. `ImperialSoccerLayout.h`를 공유하므로 실제 스폰·홈 좌표·패드·LOS 조종자 위치가 일치한다.

R6의 실제 실행 창에서10대 기체·홈과 렌더 인스턴스의 패드 좌표를 각각 내보내 대조했다. 10대를 하나씩 선택해 LOS 조종자 위치도 Blue x=-9.5m / Red x=9.5m,해당 역할의 같은Y인지 확인했다. 초기 방향을 포함한 **69개 화면 검사 모두 통과**했다. 근거는 `Saved/Verification/ui-20261026-210203-219/result.json`과 각 역할의 실제CSV·화면이다. 기체 중심Z는 바닥에 안착하면 약0.2m이며 표는 평면상의 시작 위치다. 현재 모든 기체의 수동 비행은ANGLE이다.

| 기체 표시 | 구현 | 근거 |
|---|---|---|
| 팀 LED | 적도 부근 빨강/파랑96소자 원형 | FIDA 팀 식별 규정 |
| 역할 LED | 상부 역할색80소자 원형 | FIDA 역할 색상 |
| 전방 방향 LED | 아래쪽 흰색12소자 단일 호 | Betaflight 방향 팔레트 참고,자체 배치 |
| 후면 LED | 아래쪽 빨강12소자×두 줄 | Betaflight 방향 팔레트 참고,자체 배치 |
| 형상 구분 | 전방 한 줄·후방 두 줄,팀 띠·역할 띠와 높이 분리 | 붉은 팀과 붉은 후미를 형태로도 구별하는 설계 선택 |

[Betaflight LED Strip 공식 문서](https://betaflight.com/docs/wiki/guides/current/LED-Strip-Functionality)의 Orientation 팔레트는 North 흰색/South 빨강을 사용한다. 이를 기체 전후 식별의 디자인 근거로 참고했다. 이 추가 방향등 색상이 FIDA의 의무 규격이거나 HELSEL 제품의 정확한 기본 배선이라는 의미는 아니다. 방향등을 추가해도 공식 팀·역할 띠를 대체하지 않는다. 별도의 점멸 경고·실물 LED 제어 펌웨어 연동은 구현하지 않았다.
