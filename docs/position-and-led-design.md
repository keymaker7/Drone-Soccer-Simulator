# 포지션별 시작 패드와 식별 LED

확인·구현: 2026-10-26 KST. [FIDA Class40 규정](https://fidasystem.com/rules.html)의 시작선은 짧은 끝선에서1.5m 안쪽이며 선 또는5개 점으로 표시한다. 규정은 다섯 역할의 좌우 순서를 지정하지 않는다. 사용자 요청으로 스트라이커는 각 시작선의 정중앙에 둔다. 각 팀 조종자 기준 왼쪽부터 리베로·가이드·스트라이커·스위퍼·키퍼의 **훈련용 배치**를 선택했다. 페널티킥의 스트라이커 중앙선 출발을 일반 경기 시작 배치에 섞지 않았다.

| 번호·포지션 | 역할 LED·패드 | Blue 시작점(m) | Red 시작점(m) |
|---|---|---|---|
| 1 Striker | 초록·S 태그 | (-6.5,0) | (6.5,0) |
| 2 Guide | 분홍·G 태그 | (-6.5,-1.25) | (6.5,1.25) |
| 3 Libero | 하늘색 | (-6.5,-2.5) | (6.5,2.5) |
| 4 Sweeper | 노랑 | (-6.5,1.25) | (6.5,-1.25) |
| 5 Keeper | 흰색 | (-6.5,2.5) | (6.5,-2.5) |

좌표는 경기장 중심 기준이다. 모든 기체의 초기 몸체 전방은 중앙선을 향한다(Blue +X,Red -X). 역할색은 공식 기준이고,패드의 좌우 순서·글자·화살표는 훈련용 표시다. 패드는 충돌체 없는 바닥 표시이며 출발 장애물을 추가하지 않는다. `ImperialSoccerLayout.h`를 공유하므로 실제 스폰·홈 좌표·패드·LOS 조종자 위치가 일치한다.

R6의 실제 실행 창에서10대 기체·홈과 렌더 인스턴스의 패드 좌표를 각각 내보내 대조했다. 10대를 하나씩 선택해 LOS 조종자 위치도 Blue x=-9.5m / Red x=9.5m,해당 역할의 같은Y인지 확인했다. 초기 방향을 포함한 **69개 화면 검사 모두 통과**했다. 근거는 `Saved/Verification/ui-20261026-210203-219/result.json`과 각 역할의 실제CSV·화면이다. 기체 중심Z는 바닥에 안착하면 약0.2m이며 표는 평면상의 시작 위치다. 현재 모든 기체의 수동 비행은ANGLE이다.

| 기체 표시 | 구현 | 근거 |
|---|---|---|
| 팀 LED | 적도 부근 빨강/파랑96소자 원형 | FIDA 팀 식별 규정 |
| 역할 LED | 상부 역할색80소자 원형 | FIDA 역할 색상 |
| 전방 방향 LED | 아래쪽 흰색12소자 단일 호 | Betaflight 방향 팔레트 참고,자체 배치 |
| 후면 LED | 아래쪽 빨강12소자×두 줄 | Betaflight 방향 팔레트 참고,자체 배치 |
| 형상 구분 | 전방 한 줄·후방 두 줄,팀 띠·역할 띠와 높이 분리 | 붉은 팀과 붉은 후미를 형태로도 구별하는 설계 선택 |

[Betaflight LED Strip 공식 문서](https://betaflight.com/docs/wiki/guides/current/LED-Strip-Functionality)의 Orientation 팔레트는 North 흰색/South 빨강을 사용한다. 이를 기체 전후 식별의 디자인 근거로 참고했다. 이 추가 방향등 색상이 FIDA의 의무 규격이거나 HELSEL 제품의 정확한 기본 배선이라는 의미는 아니다. 방향등을 추가해도 공식 팀·역할 띠를 대체하지 않는다. 별도의 점멸 경고·실물 LED 제어 펌웨어 연동은 구현하지 않았다.

[HELSEL 공식 조립 자료](https://www.helselgroup.com/_files/ugd/f9f7fd_f8c9cc9a0b484b0e9491aad3a0abb093.pdf)의 적도 팀 띠·상부 역할 표시와 내부 프레임을 함께 참고했다. 제조사 그림이나 사진은 포함하지 않고 직접 만든 메시만 배포한다. 실제 Unreal 실행 렌더:

## 사용자 지정 중앙 배치·하단 띠 — 2026-10-26

위 좌표표는 새 배치다. R6의69개 화면 검사와 위 R4 이미지는 변경 전 기록이므로 새 배치의 검증으로 대신하지 않는다.

- Striker는 양 팀 시작선의 정중앙 y=0. Blue x=-6.5m, Red x=6.5m다. 경기장 중앙선 x=0 출발과 다르다.
- 양 팀 조종자 기준 왼쪽부터 Libero / Guide / **Striker** / Sweeper / Keeper. 간격1.25m와 팀별 거울 배치는 유지한다.
- 공유 배치 함수가 출발 패드·기체 스폰·홈 좌표·LOS 조종자 위치를 함께 결정한다.
- 양 팀 Striker에는 초록색, Guide에는 분홍색 하단 띠를 추가했다. 사용자의 '양쪽으로 두 개씩'을 좌우 각각2개, 기체당 총4개로 해석했다.
- 각 띠는 이어진3개 평면 조각으로 표시한다. 기체당12개 메시 인스턴스가4개 띠를 구성한다. 나머지 역할에는 추가하지 않는다.
- 루트0.4배 스케일과 별개로 실제 cm 크기를 유지한다. 현재 표시 길이는7.8cm, 폭2.4cm이며 바닥에 놓인 기체에서도 끝이 바닥을 뚫지 않도록 배치했다.
- 속도와 ARM에 따른 약한 흔들림은 시각 근사다. 천의 질량·접촉·파손을 푸는 물리 시뮬레이션이 아니다. 기존 비행 질량이나 충돌체를 바꾸지 않는다.
- 기존 팀 LED·역할 LED·상부S/G 태그와 별도로 표시한다. 하단 띠 탈락·득점 불인정·공격수 승계의 경기 코드 연동은 아직 구현하지 않았다.
