각 단계는 실패 재현→수정→독립 검사→Unreal 실행본→배포 ZIP→소스 지문/해시 대조→문서·GitHub 순서로 진행한다.
같은 PC의 자동 시험으로 다른 물리 PC나 실제 조종기 검사를 완료 처리하지 않는다.
실물 조종기는 배터리 부족으로 분리된 상태라는 마지막 사용자 보고를 따른다. 실제 장치 입력이 필요한 검사는 연결 후 별도로 진행한다.

R7에는 다른 작업의 변경이 있어 이번 전력·배포 통합은 별도 R8 작업 폴더에서 검사한다.
관련 없는 새 소스는 자동으로 포함하지 않고, 다른 작업의 결과는 확인 후 다음 통합 단계에서 반영한다.
