# 스트라이커 하단 식별 띠 장착 조사

확인일: 2026-10-26. 현재 프로젝트의 기준은 **FIDA Class40**이다. FAI 자료는 하단 리본 형태를 이해하는 비교 자료이며, 두 단체의 규정을 합쳐 적용하지 않는다.

## 공식 자료에서 확인한 내용

| 근거 | 확인 내용 | 해석 범위 |
|---|---|---|
| [FIDA 제5차 개정 원문](https://dronesoccer.org/static/files/Rule-book-1.pdf), 인쇄9쪽 2-4/2-5 | Striker·Guide의 태그·역할색과 태그 탈락/식별 조건 | 역할 표시와 득점 자격의 근거. 웹 요약보다 원문 조건을 우선 확인 |
| [FAI 2026 Sporting Code](https://fai.org/sites/default/files/document/file/SC4_volume_CIAM_F9_Drone_sports_2026.pdf), 인쇄 20쪽 B.1.6 | 주최자가 Striker 기체 아래에 매달리는 리본 또는 얇은 깃발을 요구할 수 있음 | 아래로 늘어뜨리는 형상 근거. FIDA의 의무·색상·개수 근거로 사용하지 않음 |
| [FAI 2025 세계선수권 공식 기사·경기 사진](https://www.fai.org/news/intense-first-rounds-fai-world-drone-soccer-championship), 2025-11-16 | 구형 기체에 부착한 리본으로 Striker를 식별한다고 설명. 사진 설명은 빨간 팀 Striker의 빨간 리본을 명시 | 실제 대회 사용 사례. 초록·분홍 FIDA 역할색과 구분 |

따라서 장착 형태는 **기체 아래에 식별 리본을 매달아 구별하는 방식**으로 이해할 수 있다. 기체를 둘러싼 팀 LED 링, 역할 LED와 구별해서 모델링한다. 이 자료만으로 리본의 정확한 고정점을 배터리 트레이나 특정 보호구 연결부로 단정할 수는 없다.

추가 검토에서 웹 요약에 생략된 원문 조건을 확인했다. 사용자 요청의 엄격 태그 정책은 보존하되 공식 판정과 구분한다. 자세한 보완은 [자체 피드백·정밀 계획](simulator-plan-review.md)에 기록했다. 현재 게임의 고정부·득점 코드를 수정한 것은 아니다.

## 확인하지 못한 세부사항

이번에 확인한 공식 조항에는 다음 항목을 확정할 자료가 없었다.

- 띠의 정확한 길이·폭·두께·섬유 재질.
- 볼트·케이블타이·벨크로·매듭 중 어떤 방식으로 고정하는지.
- 좌우 각각 2개인지, 부착 지점과 리본 가닥 수가 같은지.
- 여러 띠 중 일부만 떨어졌을 때 태그 자격을 판단하는 세부 기준.

제조사 일반 조립 자료만으로 경기용 태그의 고정 방식을 확인했다고 기록하지 않는다. 세부 장착은 적용 대회의 장비 지침·태그 실물 또는 고정부가 보이는 근접 자료를 추가 확인해야 한다. FAI 사진의 색상·개수를 FIDA 규격으로 일반화하지 않는다.

## 이 프로젝트의 설계와 다음 작업

**현재 구현:** 사용자 요청에 따라 양 팀 Striker에 초록, Guide에 분홍 하단 띠를 **좌우 각각 2개, 기체당 4개** 표시한다. 이 개수는 사용자 지정이며 공식 필수 개수로 주장하지 않는다. 메시·간단한 흔들림만 있으며 질량·충돌·cloth·탈락을 계산하지 않는다.

**다음 설계안:** 아래 항목은 조사로 확정된 실물 장착 사양이 아니라 시뮬레이터 개발 제안이다.

1. 하단 고정점·리본 가닥을 별도 요소로 두고 위치·치수를 교체 가능하게 만든다.
2. 윗부분의 고정과 아래쪽 자유단을 시각적으로 구분한다. 고정부 형태는 실물 근거 확보 후 확정한다.
3. 하향류·기체 이동·충돌에 따른 휨을 단계적으로 검증한다. 실측 전 계수는 실험값으로 표시한다.
4. `TagAttached`·`TagValid`와 득점 권한을 관리하고, 탈락 사건을 경기 기록에 남긴다.
5. 부분 탈락의 유효 기준을 대회 지침과 대조한 뒤 구현한다. 임의로 한 가닥 탈락 즉시 자격 상실로 결정하지 않는다.
6. 네트·프로펠러 얽힘, 탈락, 재부착, Guide 승계는 별도 요구사항과 시험을 거친다.

이번 작업은 자료 조사·문서 반영이다. 기체 메시·게임 판정·배포 실행 파일은 수정하지 않았다. [현재 포지션·LED 설계](position-and-led-design.md), [경기 규정](rules-sources-2026.md), [개발 계획](development-roadmap.md)을 함께 참고한다.
