# 개발 순서와 완료 기준

2026-10-26 사용자 제공 계획을 작업 기준으로 등록했습니다. 아래의 96개 화면 검사는 R4 기록이며,현재 R5는 화면119개·보정 수학159개를 통과했습니다. 항목의 체크는 구현과 실제 검증을 구분해 갱신합니다.

현재 프로젝트는 **기본 비행·5대5 경기·포지션과 LED·자율 훈련이 구현된 시제품 단계**입니다. 다음 개발은 **Boxer 실조종 완성 → 제어·통신 안정화 → 경기 운영 완성 → 그래픽·성능 개선 → 배포** 순서로 진행하는 것이 좋습니다.

소스, 설정, 실행 스크립트, 물리 모델, 경기 판정, 검증 기록을 점검했습니다. 저장된 결과에서 **화면 조작 96개 항목 통과**, **30·60·120Hz 물리 시나리오 성공**을 확인했습니다. 이 문장은 계획 작성 당시의 점검 범위입니다. 이후 변경·실행 결과는 verification.md의 버전별 기록을 따릅니다.

**점검에서 확인한 주요 보완점**

| 분야 | 현재 상태 | 다음에 해결할 점 |
|---|---|---|
| Boxer | 연결·원시 입력·4축 끝값 관찰 기록 있음 | 실제 스틱 배정·방향·중립·최저 스로틀 확정, USB 비행 |
| 비행 제어 | 모터 힘·PID·센서·배터리 모델 있음 | 제어 계산이 화면 프레임에 영향받음 |
| 경기 판정 | 기본 득점·오프사이드·세트 진행 구현 | 공격수 승계·심판 운영·페널티·동점 처리 보강 |
| 자율 훈련 | 실제 SDACS APF 연동 | 이전 명령의 늦은 응답 처리, 귀환 중 통신 장애 검증 |
| 기체·LED | 역할색·팀 띠·전후방 표시 구현 | 실제 LOS 거리에서 식별성 검증 |
| 그래픽 | Lumen·재질·경기장·절차적 기체 구현 | 가까이서 보는 자산 품질과 목표 PC 성능 검증 |
| 설치·배포 | 빌드·실행 스크립트 있음 | 개발 PC 경로 기본값, 의존성 버전·실행 파일 관리 개선 |
| 자동 검증 | 독립·실행·화면 시험 있음 | GitHub 자동 검사와 버전별 결과 연결 필요 |

특히 경기 코드에서 득점 가능한 공격수가 현재 **기체 ID 0·5로 고정**되어 있습니다. 공격수 승계를 추가할 때는 역할·LED·득점 권한이 함께 바뀌도록 구조를 고쳐야 합니다. 자율 통신 응답에는 명령 세대를 구분하는 번호가 보이지 않아, 모드 전환 직전 요청의 응답이 뒤늦게 도착하는 상황도 우선 검증해야 합니다.

아래 목록은 **권장 개발 순서**입니다. 완료 기준을 만족한 뒤 다음 단계로 넘어가도록 잡았습니다.

**1. 기준 버전과 재현 환경 확정 — P0, 모든 작업의 출발점**

- [ ] 현재 정상 동작하는 소스·콘텐츠·실행 파일을 같은 버전으로 묶기.
- [ ] 실행 화면에 버전명·소스 커밋·빌드 날짜 표시.
- [ ] 시험 결과에 사용한 소스 커밋과 설정값 기록.
- [ ] 에디터 실행과 배포 실행 파일의 차이 정리.
- [ ] 소스가 바뀌면 기존 실행 파일을 구분해 표시.
- [ ] 엔진·Python·SDACS 경로를 한곳에서 설정하도록 통합.
- [ ] 설치된 필수 도구를 검사하고 누락 항목을 한국어로 안내.
- [ ] 새 폴더에 GitHub 프로젝트를 받아 설치·빌드·실행 재현.

**완료 기준:** 개발 폴더의 기존 임시 파일 없이도 새 복사본에서 실행할 수 있고, 어떤 소스로 만든 실행 파일인지 확인할 수 있을 것.

**2. Boxer 조종기 연결과 실비행 완성 — P0**

- [ ] 실제 스틱을 하나씩 움직여 Roll·Pitch·Yaw·Throttle 배정 확정.
- [ ] Mode 1·Mode 2 선택 기능과 설명 추가.
- [ ] 각 축의 양의 방향을 기체 반응과 대조.
- [ ] 스틱 중립·최소·최대 범위 보정.
- [ ] 스로틀 최저 위치와 ARM 허용 조건 확인.
- [ ] 사용자별 데드존·반전·감도·Expo 설정.
- [ ] 연결된 장치 이름과 선택된 장치가 명확히 보이도록 개선.
- [ ] 조종기 분리·재연결 시 보정 정보가 올바른 장치에 적용되는지 확인.
- [ ] 실제 스위치를 ARM·비상 정지·초기화에 배정.
- [ ] USB 분리·포커스 상실·입력 중단 시 동작 시험.
- [ ] USB 수동 이륙·호버·좌우 이동·선회·착륙 시험.
- [ ] 입력부터 화면 반응까지 지연 측정.

**완료 기준:** 실제 Boxer로 연속 수동 비행을 수행하고, 분리·재연결 후 임의로 모터가 켜지지 않을 것. 이 단계에는 사용자의 실제 스틱·스위치 조작이 필요합니다.

**3. 비행 제어와 시간 간격 안정화 — P0**

- [ ] 입력 수집·제어 계산·물리 계산·화면 표시의 갱신 주기 분리.
- [ ] 일정한 주기로 PID가 계산되도록 구조 변경.
- [ ] 물리 계산과 화면 계산 사이 상태 전달 방식 정리.
- [ ] 느린 프레임에서 같은 힘이 과도하게 적용되지 않는지 검사.
- [ ] 20·30·60·120·240FPS 조건 비교.
- [ ] 순간적인 프레임 지연과 연속적인 저성능 상황 시험.
- [ ] PID 포화·적분 누적·모터 출력 제한을 화면과 로그로 확인.
- [ ] 배터리 저전압에서 호버·자세 제어가 유지되는 범위 측정.
- [ ] 초기화·기체 선택·조종 방식 전환 시 제어 상태 정리.
- [ ] 실험 물리 켜기·끄기를 동일 조건으로 비교하는 시험 추가.

**완료 기준:** 지원하는 프레임 범위에서 비행 오차와 자세 흔들림이 정한 허용 범위에 들어갈 것. 현재 통과한 세 가지 시험만으로 모든 프레임 조건을 보장하지 않을 것.

**4. 자율 훈련과 통신 장애 처리 — P0**

- [ ] 요청마다 세션·명령 번호 부여.
- [ ] 모드가 바뀌기 전 요청의 늦은 응답 무시.
- [ ] 초기화 후 이전 목표점이 다시 적용되지 않도록 처리.
- [ ] 임무·HOLD·RETURN 각각의 통신 장애 동작 정의.
- [ ] 귀환 도중 브리지가 종료되는 상황 시험.
- [ ] 연결 복구 후 자동 재개 여부를 명확히 결정.
- [ ] 실제 요청 간격과 전송하는 시간값의 일치 여부 점검.
- [ ] SDACS 소스 버전과 통신 형식 버전 확인.
- [ ] 잘못된 응답·중복 ID·누락 기체·비정상 좌표 시험 확대.
- [ ] 골대·네트·수동 조종 기체가 섞인 경로 회피 시험.
- [ ] 마주 오는 기체·교차 비행·막힌 경로에서 정체 복구.
- [ ] 충돌 횟수·최소 거리·귀환 오차·귀환 시간을 자동 기록.

**완료 기준:** 브리지를 중간에 종료하거나 지연시켜도 정의된 동작으로 전환하고, 이전 명령이 새 명령을 덮어쓰지 않을 것.

**5. 경기 규정과 심판 운영 완성 — P1**

- [ ] 규정 조항별로 구현·부분 구현·미구현 표 작성.
- [ ] 적용 규정과 개정일을 게임 안에 표시.
- [ ] 고정 기체 ID 대신 팀별 현재 공격수를 관리.
- [ ] 공격수 승계 시 득점 권한·역할명·LED·태그 동시 변경.
- [ ] 공격수 태그 유효 상태 관리.
- [ ] 파손·퇴장·경기 제외 기체와 오프사이드 판정 연결.
- [ ] 경고·퇴장·페널티를 입력하는 심판 화면.
- [ ] 경기 정지·재개·시간 보정 기능.
- [ ] 동점·연장·승부치기는 선택한 규정에 따라 구현.
- [ ] 세트 변경 시 점수·역할·기체 상태 초기화 점검.
- [ ] 종료 직전 득점·골대 접촉·역방향 진입 경계 시험.
- [ ] 득점과 판정의 시각·기체·사유를 사건 기록으로 저장.
- [ ] 잘못 입력한 심판 판정의 취소·정정 이력 관리.

**완료 기준:** 준비부터 경기 종료까지 한 경기를 운영할 수 있고, 모든 득점·페널티의 근거를 기록으로 확인할 수 있을 것.

**6. 포지션·기체·LED 식별성 개선 — P1**

- [ ] 기존 역할별 시작 위치와 홈 위치의 일치 자동 검사.
- [ ] 공식 시작선과 훈련용 좌우 배치를 화면에서 구분.
- [ ] 양 팀 조종자 위치에서 다섯 포지션을 각각 식별하는 시험.
- [ ] 역할 번호·기체 번호·팀 표시의 크기 조정.
- [ ] 역할색을 색상 외에 숫자·기호로도 구분.
- [ ] 흰색 전방 한 줄·빨간 후방 두 줄의 가시성 확인.
- [ ] 빨간 팀 띠와 빨간 후미등이 겹쳐 보이는 상황 개선.
- [ ] 발광이 번져 보호구와 기체 방향이 사라지는 현상 조정.
- [ ] ARM·연결 상실·배터리 경고의 보조 표시 설계.
- [ ] 보조 경고가 팀·역할 식별을 가리지 않도록 제한.
- [ ] 실제 LED 소자 크기·간격·설치 위치를 설정값으로 관리.
- [ ] 역할 승계와 기체 교체 후 모든 표시의 일치 검사.

**완료 기준:** 실제 LOS 시점에서 팀·역할·앞뒤 방향을 구별할 수 있을 것. 공식 규정과 자체 디자인 선택의 구분을 유지할 것.

**7. 실기체 물리 보정 — P1, 측정 자료 확보와 병행**

- [ ] 비교 대상으로 삼을 실제 기체·프로펠러·배터리 구성 확정.
- [ ] 총질량·부품별 질량·무게중심 측정.
- [ ] 축별 관성 추정 또는 측정.
- [ ] 스로틀별 추력·전류·회전수 측정.
- [ ] 모터 가속·감속 응답과 출력 편차 측정.
- [ ] 배터리 잔량별 전압 강하·호버 스로틀 비교.
- [ ] 전진·측면·수직 이동의 항력 계수 보정.
- [ ] 바닥·벽·기체·네트 충돌의 반발과 감쇠 비교.
- [ ] 지면 근접·천장 근접·상하 기체 간섭 측정.
- [ ] 회전수 변화에 따른 추가 회전자 토크 검토.
- [ ] 실측값과 가정값을 설정 파일에서 구분.
- [ ] 각 측정 조건과 오차를 보정 보고서로 정리.

**완료 기준:** 모델이 실기체와 얼마나 다른지 수치로 제시할 수 있을 것. 측정 자료가 없는 계수는 계속 실험값으로 표시할 것.

**8. 실사 수준의 그래픽과 성능 — P1**

- [ ] 경기장 전체의 조명·재질·색감 기준 장면 선정.
- [ ] 보호구 봉·연결부·체결부·카본 프레임의 근접 품질 개선.
- [ ] 배터리 스트랩·배선·수신기·모터 하우징 세부 표현.
- [ ] 카본·플라스틱·고무·금속의 반사와 거칠기 분리.
- [ ] 바닥 선·미세 흠집·네트 고정부·골대 마감 개선.
- [ ] 밝은 경기장과 어두운 배경에서 LED 노출 조정.
- [ ] 프로펠러 회전 표현과 실제 회전 상태 연결.
- [ ] 비행·충돌·네트 접촉 소리 추가.
- [ ] 기체·LED·네트의 거리별 표시 단계 구성.
- [ ] 다수의 LED와 네트 와이어 렌더 비용 측정.
- [ ] 저·중·고 품질 설정과 해상도 조절 제공.
- [ ] RTX 5060 목표 PC에서 실제 성능 측정.
- [ ] 정지 화면 외에 10대 비행·충돌·효과음 동시 상황 측정.
- [ ] 평균 FPS와 함께 느린 프레임·끊김·메모리 사용량 기록.

**완료 기준:** 목표 PC의 합의한 해상도와 품질에서 안정적인 성능을 유지하고, 조종 중 기체 식별을 방해하지 않을 것.

**9. 훈련 기능·사용 화면·리플레이 — P2**

- [ ] 첫 실행 장치 연결·조종 안내.
- [ ] 한국어 메뉴와 용어 통일.
- [ ] 수동 경기·자율 훈련 모드 선택을 명확히 표시.
- [ ] 호버·직선·선회·골대 통과 단계별 훈련.
- [ ] 포지션별 출발·복귀·수비 위치 훈련.
- [ ] 초보자용 자세 안정화 모드를 별도로 검토.
- [ ] 충돌 수·통과 시간·경로 오차로 훈련 평가.
- [ ] 세션별 기록과 개인 최고 기록 저장.
- [ ] 기체 상태·입력·경기 사건을 연속 기록.
- [ ] 리플레이 일시정지·저속 재생·시점 변경.
- [ ] 점수 사건 전후 구간을 바로 확인하는 기능.
- [ ] 화면 배율·해상도 변화에서도 메뉴 가독성 유지.

**완료 기준:** 처음 사용하는 사람이 도움 없이 연결·훈련 시작·결과 확인까지 진행할 수 있을 것.

**10. 여러 사람의 경기 참여 — P2, 기본 안정화 이후**

현재 10대 기체와 선택 조종 기능이 있다는 사실만으로 10명이 동시에 경기할 수 있는 것은 아닙니다. 실제 팀 경기를 목표로 한다면 별도 개발 범위로 잡아야 합니다.

- [ ] 한 PC의 여러 조종기와 여러 PC 접속 중 지원 방식 결정.
- [ ] 플레이어별 팀·역할·기체 배정.
- [ ] 경기 대기실·참가·준비 완료 흐름.
- [ ] 경기 상태와 득점 판정을 서버에서 일관되게 처리.
- [ ] 기체 위치·회전·입력 동기화.
- [ ] 지연·패킷 손실·접속 해제·재접속 처리.
- [ ] 심판·관전자 권한과 시점 분리.
- [ ] 실제 5대5 동시 접속 경기 시험.

**완료 기준:** 선택한 접속 환경에서 10명이 동시에 조종하고, 모든 화면의 점수·경기 시간이 일치할 것.
