4. 구체적인 내용

여기에는 파일 이름·설명을 적습니다. 실제 파일은 저장한 보고서와 함께 직접 전달합니다. 이 양식이 파일을 읽거나 첨부·업로드하지 않습니다.

비행 기록·진단 자료를 함께 보내려면
  1. F6으로 비행 기록을 시작하고, 착륙·DISARM 후 다시 F6으로 종료합니다.
  2. Win+R에 %LOCALAPPDATA%\ImperialWingsSimulator\Saved를 넣어 엽니다. FlightLogs의 JSONL, Reports의 CSV, 필요한 Diagnostics 파일만 선택합니다.
  3. 공유 전에 개인 경로·장치 정보를 확인합니다. Config의 개인 조종기 보정이나 Saved 폴더 전체는 첨부하지 않습니다.
  4. 저장한 보고서와 선택 파일을 사용자와 합의한 채팅·메일 등으로 전달합니다. 자동 전송되지 않습니다.
