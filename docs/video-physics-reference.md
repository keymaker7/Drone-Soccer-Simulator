## 구현·검증 순서

1. 촬영 원본 FPS·프레임 시각·카메라 고정/이동·가림과 기체 식별의 신뢰도를 기록한다. 표시 경기 시각과 영상 시각은 다른 열로 둔다.
2. 바닥 네 모서리의 평면 보정은 바닥에만 적용한다. 공중 기체의3D 위치·깊이·속도는 단일 평면 변환으로 확정하지 않는다. 골대 규격도 해당 대회의 실제 규정 확인 후 사용한다.
3. 실제 질량·중심·관성, 추력대 곡선·모터 응답, 전압 하강, 재질별 접촉/낙하 시험을 확보한다. 단위·장비·오차·출처를 물리 프리셋에 저장한다.
4. 이륙→직선→감속→선회→착지→단일 접촉→밀집 접촉 순서로 영상과 동일 조건의 시험을 구성한다. 기존 호버/접촉/득점 smoke 결과는 내부 회귀 검사이며 실기체 일치의 증명이 아니다.
5. 30/60/120FPS에서 동일 초기 조건의 위치·자세·정착 시간·에너지 증가를 비교한다. 다른 GPU 렌더 성능과 USB 입력 지연은 별도로 측정한다.
6. 조정에 사용하지 않은 영상/시험을 남겨 검증한다. 계수 변경 전후 오차와 부작용을 기록하고 미측정 항은 실험값으로 표시한다.

이번 변경은 **참고 영상 등록과 검증 계획**이다. 검토 프레임만으로 기존0.9kg 모델·추력·마찰·반발·PID 상수를 변경하지 않았다. 실제 기체와 정확히 일치한다는 주장은 실측과 독립 비교 이후에만 가능하다.
