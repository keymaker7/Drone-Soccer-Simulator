## 우선순위와 작업 공간

1. **기존 작업 보존과 실행 환경 확인.** 원본 `E:\ImperialWingsSimulator`의 미커밋 문서 8개와 R11의 진행 중 Topgun 작업은 유지한다. 원본 main은 오래된 `a5f817a`이므로 최신 AI 대전까지 포함된 `12150ce`에서 별도 `codex/korean-radio-12150ce-20261028` 브랜치와 `E:\Builds\ImperialWings-KoreanRadio-20261028` 작업 폴더를 만들었다. 기존 폴더를 pull/reset/checkout하지 않는다.
2. **한국어 안내와 간단 조종기 흐름.** 이미 있는 장치 선택·Mode1/2·단계형 보정을 유지하고 한국어 기본 표시와 영어 전환, 단계/오류/다음 동작을 개선한다. 언어 설정은 개인 보정과 분리한다.
3. **다른 PC와 저장·재연결 안전.** 실제 Boxer의 러더 V·스로틀 Z 기록은 참고이며 다른 장치의 축을 강제하지 않는다. 장치 식별·전체 범위·중립·방향·최저 스로틀을 현장에서 다시 확인한다. 저장 실패가 이전 정상 보정을 삭제하지 않게 한다. 재연결은 명시적 활성화 후 별도 ARM을 유지한다.
4. **자동 회귀와 Unreal 실행/화면 확인.** 새 사용자 경로를 써 개발자 보정을 읽거나 덮어쓰지 않는다. 동일 PC의 새 폴더 검사는 다른 PC 또는 실제 USB 손실 시험으로 보고하지 않는다.

기존 최신 소스에는 간단 장치 카드, 저장 조종기 F8 연결, Mode1/2, 사용자별 저장, 레이트·Expo·아밍키가 있으므로 이를 중복 개발하지 않는다. AI·Topgun·네트워크·물리 구조 변경은 이번 범위에 포함하지 않는다.

## 실제 조종기와 다른 PC 확인 순서

1. 데이터 USB 케이블과 조종기의 USB Joystick 모드를 확인하고 Windows `joy.cpl`에서 실제 장치 입력을 확인한다.
2. 게임에서 자신의 장치를 직접 선택한다. Mode2의 왼쪽 세로는 스로틀, 왼쪽 좌우는 러더이며 실제 축 문자는 USB 설정에 따라 달라질 수 있다.
3. 단계형 보정으로 네 축 끝값·방향·중립·최저 스로틀을 직접 측정한다. 개발 PC의 실제 기록은 Roll X / Pitch Y / 러더 V / 스로틀 Z지만 이를 다른 PC의 정답으로 적용하지 않는다.
4. 검토·저장 → 최저 스로틀에서 USB 활성화 → 패널 닫기 → 별도 ARM 순서로 진행한다. 재실행·케이블 재연결만으로 활성화하거나 ARM하지 않는다.
5. 포커스 상실·USB 손실 이후 다시 선택/활성화/ARM 조건을 확인한다. 실제 비행 중 케이블 분리 시험은 현장 시험자가 안전한 훈련 조건에서 별도로 수행한다.
