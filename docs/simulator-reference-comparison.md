# 다른 드론 시뮬레이터 참고: 조종기·LOS 훈련·복기

확인일: **2026-10-27 KST**. [기존 비교](simulator-benchmark.md)를 공식 자료로 재확인하고 다음 작업을 구체화한 문서다. 비교 제품을 설치·조종한 시험은 수행하지 않았다. 아래의 **확인한 기능**은 제작사 문서의 설명이며, 물리 정확도·조종기 호환성·훈련 효과를 독립 검증했다는 뜻은 아니다.

Imperial Wings는 경기장 밖 파일럿의 **LOS·ANGLE 수동 조종**을 유지한다. 화면 안내와 훈련·분석 방법을 참고하며 타 제품의 FPV 기본값, 기체 수치, 화면·메시·재질·소스코드는 가져오지 않는다. ANGLE의 수평 복원과 고도 유지는 별개다.

## 현재 기반과 남은 간격

- **조종기:** Mode 1/2 선택·단계별 실제 축 보정·프로필 호환은 v0.7.3에 구현되어 있다. v0.7.4 준비 소스는 선택형 `DIRECT/PRECISION` 스로틀을 제공한다. Precision은 기본 OFF이며 정규화 스틱 55% 부근의 감도를 낮추는 입력 곡선이다. 55%를 실제 호버점으로 보장하거나 모터 추력 곡선을 대체하지 않는다. 곡선 미리 보기·중립 품질 진단·실제 Mode 1 연속 비행은 별도 후속 검사다.
- **훈련:** 현재 자동 Practice와 수동 조종 기반을 활용할 수 있지만, 자동 비행 성공을 사용자의 수동 이륙·호버·착륙 합격으로 기록하면 안 된다. 아래의 단계형 평가 과제는 신규 제안이다.
- **복기·튜닝:** F6 JSONL은 비행 진단 기록이며 게임 내 완전한 리플레이가 아니다. 열 대의 상태·LED·경기 사건을 임의 시각으로 재생하는 기능, 영상 내보내기와 사용자 기체 튜닝 화면은 완료로 표시하지 않는다. 물리 계수는 실측 전까지 실험 설정으로 표시한다.

## 다음 세 가지 우선 작업

아래 순서는 조사에 근거한 개발 제안이다. 기존 [기능 명세](simulator-feature-plan.md)의 번호와 완료 조건을 사용하며, 이 문서 작성으로 구현 상태를 바꾸지 않는다.

| 순서·기능 번호 | 구체 작업 | 완료 판정에 필요한 검사 |
|---|---|---|
| **1. 입력을 눈으로 확인** — INP-03·08·09·11, CTL-08 | 조종기 설정에 Mode 1/2 손 배치, 실제 입력 막대, `DIRECT/PRECISION` 곡선과 현재 출력점을 함께 표시한다. 중립 흔들림·최저 스로틀·끝 범위 확인 결과를 저장 전 검토에 연결한다. | 양 모드에서 실제 움직인 축과 안내·그림이 일치해야 한다. 곡선의 0/100% 끝값과 단조성을 지키며 ARM 최저 스로틀 판정에는 곡선 전 입력을 사용한다. 미연결·보정 취소·잘못된 저장값·재실행을 검사한다. 실물 입력 증거는 자동 시험 결과와 따로 남긴다. |
| **2. LOS 입문 과제** — TRN-01~04·08·12, CTL-02 | 연결 확인 → 최저 스로틀·ARM → 이륙 → 호버 → 기수/LED 방향 식별 → 골대 접근 → 착륙 순서로 한 행동씩 안내한다. 실패 시 이유와 이전 기록을 남기고 같은 조건으로 재시도한다. | 최초 호버 시험안은 목표 1m, 고도 오차 ±0.2m, 시작점 수평 반경 0.5m에서 5초 유지로 둔다. 이는 조정 가능한 초기 훈련 기준이며 공식 경기 규정이나 실기체 숙련 기준이 아니다. 수동/자동 입력원을 기록하고 수평 복원 중 상승도 평가한다. 시작 위치·배터리·설정을 같게 맞춰 반복한다. |
| **3. 기록과 설정을 함께 복기** — RPL-01·03·04·06·10, DAT-14, PHY-12·CTL-06 | 먼저 기존 F6의 곡선 전 스로틀·명령·위치·속력·전력 제한을 같은 시간축으로 비교한다. 수직 속도는 별도 기록 필드를 추가하거나 위치 차분의 추정값임을 표시한다. 이어 상태 녹화와 LOS/골대/전체 시점 재생을 만든다. 비행 당시 기체·입력·배터리 설정과 버전을 붙여 튜닝 전후를 비교한다. | 빠진 샘플·지원하지 않는 파일을 알리고 임의 시각 이동 때 입력·상태·사건이 맞아야 한다. 재생은 실제 기체 조종권·충돌·득점과 분리한다. 저장 상태 재생을 동일 Chaos 계산의 재현으로 주장하지 않는다. 기체 설정은 단위·범위·실험/실측 출처·되돌리기를 갖추기 전 무제한 편집에 노출하지 않는다. |

위 세 항목의 수동 검증은 실제 조종기가 준비된 뒤 수행한다. 독립 고정주기 제어의 미완료 항목 CTL-13은 [별도 설계](fixed-step-control-design.md)를 따른다. 다른 제품에 PID 설정이 있다는 사실만으로 본 프로젝트의 120Hz 제어 또는 실기체 일치가 검증되지는 않는다.

이 문서는 공개 자료 검토와 작업 제안만 추가한다. Shipping 소스·실행 파일·현재 배포의 검증 결과는 변경하지 않았다. 구현 및 배포 현황은 [README](../README.md)와 [검증 기록](verification.md)을 기준으로 확인한다.
