# STRIKER V3 참고 모델의 근거와 범위

확인일: 2026-10-26. 이 프로젝트는 **HELSEL STRIKER V3의 공개 자료를 참고해 직접 작성한
절차적 시각 모델**을 사용한다. 제조사 제공 메시나 CAD가 아니며 제품 인증·실측 디지털 트윈을
의미하지 않는다. HELSEL·STRIKER 명칭은 참고 제품을 식별하는 용도로 사용한다.

## 공식 출처

- [HELSEL / Skyball Drone 제품 페이지](https://www.skyballdrone.com/products/striker-v3-arf-semi-assembled-set-1):
  40cm급 ARF, 3K 카본 중심 프레임·강화 복합재 보호구, 4S~6S 대응을 설명한다.
- [HELSEL 공식 조립 설명서](https://www.helselgroup.com/_files/ugd/f9f7fd_f8c9cc9a0b484b0e9491aad3a0abb093.pdf):
  18페이지 영문 문서. 별도 개정번호는 확인되지 않았고 파일 메타데이터 작성일은 2026-02-09다.
  공식 제품 페이지의 Manual 항목은 HELSEL 지원 페이지로 연결된다.
- [FIDA Class40 규정](https://fidasystem.com/rules.html): 외곽40±2cm, 경기중 질량≤1100g 등
  경기용 외형 제한의 근거다. 제품별 실제 치수·추력 데이터와는 구별한다.

이 관찰만으로 정규 십이면체나 평면 육각 격자라고 단정하지 않는다. 제품 웹 표의 400mm를
모터 대각선 간격으로 적은 항목은 보호구 외경과 혼동될 수 있으므로 실측 레버암으로 사용하지
않는다. 설명서에는 정확한 모터 중심간 거리·질량중심·관성 텐서·프로펠러 치수·추력 곡선이
제공되지 않는다. 사진의 원근이나 픽셀 길이로 실제 치수를 만들어 내지 않는다.

## 시뮬레이터 선택과 검증

외곽40cm, 현재 질량0.9kg은 경기 규격 안의 모델 설정이다. 모터 위치·추력·배터리·관성 배분,
응답·항력·접촉·IMU 계수는 별도로 조정하는 가정값이며 실제 STRIKER V3의 측정 제원이 아니다.
네 모터 힘·반작용 토크와 Chaos 강체 접촉을 사용하고 외형의 세부 봉·배선·체결부가 모두
독립 충돌체나 탄성 부품으로 계산된다는 의미는 아니다.

기존 R2의 호버·접촉 검사와 이번 참고 형상·LOS·고급 물리 변경 이후 검증을 구분한다.
현재 형상과 물리 통합의 실제 시험 결과는 [검증 기록](verification.md), 시험용 계수 설명은
[기체 모델 기록](airframe-model.md)을 확인한다. 시각 유사성이 실기체 비행 특성의 일치를
증명하지 않는다.

설명서의 표지와 마지막 페이지는 제품·설명서의 권리가 HELSEL에 있으며 무단 복제·게시를
금한다고 명시한다. 다운로드한 설명서와 렌더·제품 사진은 검토용 로컬 `Saved/`에만 보관한다.
공개 저장소에는 공식 URL과 자체 작성한 모델·설명만 포함하며 제조사 로고·도면·사진·메시는
포함하지 않는다. [외부 권리 고지](../THIRD_PARTY_NOTICES.md)를 함께 참고한다.


## v0.6 자체 기체 모델 업데이트

실루엣·내부 구성은 위 공식 자료를 계속 참고하며, 제조사 CAD와 다른 자체 지오데식 보호구를 적용했다. 겹쳐진 위도·경도 고리 대신 12개 오각형과 30개 육각형의 총42개 개구부를 사용한다. 80개 접합점과120개 변을 둥근 봉720개 조각으로 표현하고, 접합부·적도 클램프5개·모터 냉각 슬롯48개·체결부29개·전원/모터 배선을 추가했다. 세 날 프로펠러의 끝과 단면은 둥근 타원형으로 바꿨다.

생성 원본은 `Scripts/build-cage-geometry.py`와 `Content/Data/cage-geodesic.json`이다. 보호구 봉 중심 반지름19.65cm+봉 반지름0.35cm로 외경40cm를 유지한다. 이상적인 구면 개구부의 보수적 최대 면적은131.856cm²이며 봉 두께를 빼지 않은 계산값이다. 이는 FIDA의150cm² 상한과 비교한 기하학 검사이고 실물 제작·공식 인증을 뜻하지 않는다. 탄성·강도·제품별 정확한 개구부 치수도 보증하지 않는다.

추가 메시에는 충돌·독립 강체를 사용하지 않으며, 실제 런타임 검사에서10대의 새 메시 개수·무충돌 상태·0.9kg 질량과 기존 역할/방향LED 수를 함께 확인한다. 시각 재구성은 공력·무게중심 실측 데이터를 새로 얻었다는 의미가 아니다.

## v0.7 자체 내부 기자재

`Scripts/build-electronics.py`와 Blender4.5 LTS로 원본550개 부품을 만들었다. 카본 X 프레임, FC/ESC PCB·소자/핀·납땜 패드·스페이서, 수신기·안테나, 모터 통풍구·구리 권선·샤프트, 배터리·고정부·전원/밸런스 커넥터와 배선을 표현한다. CW/CCW 프로펠러는 테이퍼·후퇴·비틀린 단면을 가진 자체 메시다.14개 PBR 재질과 자체 어두운 카본 패턴을 사용한다.

원본 `.blend`·`.glb`·생성 명세는 `ArtSource/Airframe`, 조합된 Unreal 메시/재질은 `Content/Airframe`이다. 기자재 조합82,252개 다각형, 두 프로펠러 원본 합계2,896개 다각형이며 내부 조합 외접 크기는23.512×23.5×9.723cm다. 모터 위치±9.5cm·4S14.8V1500mAh 표기는 기존 실험 모델에 맞춘 가정값이다. 모든 기자재 장식은 무충돌이며 기존0.9kg 강체·관성 가정을 바꾸지 않는다.

실제 게임 렌더는 [내부 장비 보기](images/equipment-v07.png)다. 제조사 이미지·로고·CAD는 배포하지 않는다. F9에서 보호구를 숨기는 것은 관찰 기능이며 분해·정비·실제 부품 파손 시뮬레이션을 뜻하지 않는다.
