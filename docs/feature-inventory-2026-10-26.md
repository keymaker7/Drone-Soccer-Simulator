## v0.7에 추가한 범위

1. 내부 기자재 상세 모델: 원본 Blender 부품550개,PCB/ESC·모터 권선·배터리/커넥터/배선과 형상이 있는 프로펠러. Unreal 원본 자산으로 게임에 연결하고 실제 렌더·10대 무충돌/질량 검사를 수행했다.
2. F9 장비 확인과 파일럿/추적 관찰자/전체/관객/심판 보기 분리. 장비 확인·관객/심판 화면의 수동 ARM과 비행 조작 제한을 검사한다.
3. 실제 충돌 충격량 기반 가드 내구도·마모 표시·이벤트·접촉 재질 변화. 추정 충격 일을 사용하는 모델이며 실제 재료 피로/파괴 인증은 아니다.
4. 실제12.5kg 골대의 연습 충격 반응·감쇠와 정규 경기 지지 고정,이동한 골대 기준 득점 검사·충돌 시험.
5.10대 실제 APF/Chaos 출발·HOLD·귀환·착륙,귀환 중 HTTP 장애와 재연결 시 자동 재개 금지 검사. 발견한 제어·경로·시작 위치·카메라 문제는 [자체 피드백](autonomy-feedback-v07.md)에 기록했다.

## 그다음 우선순위

v0.7.1에서 키보드 포커스·키 해제 누락·메뉴/장비/기체 전환/초기화의 입력 복구를 추가했다. 엔진 내부29개 검사와 실제 OS/USB 현장 시험의 범위는 분리한다. 실제 저장 보정은 유지하며, 포커스 상실의 수동 DISARM과 명시적인 연습 AUTO 지속을 구분한다.

| 순서 | 기능 | 완료 판단 |
|---|---|---|
| 1 | 접촉 모델 실측 보정 | v0.7 접촉 동작 검증을 기반으로 실제 가드/바닥/골대/네트 계수 측정·보정 |
| 2 | 기초 조종 훈련 | 이륙/호버/착륙·직선/방향 전환·골 통과를 과제로 수행하고 실제 경로로 평가 |
| 3 | 실물 조종 안정성 | 충전 후 실제 Boxer 방향·전체 이륙/착륙·분리/재연결·지연 검사 |
| 4 | 정비·고장 모델 | 가드/프로펠러/모터 상태를 원인별로 다루고 초기화/수리 절차 확인 |
| 5 | 경기 운영 완성 | 스트라이커 자격/승계,페널티·심판 입력,경기 단계별 ARM 제한 전체 시나리오 |
| 6 | 리플레이·코칭 | 실제 저장 세션 재생,입력/충돌/골 시점 추적,잘못된 로그 거부 |
| 7 | 여러 사람 동시 경기 | 같은 PC와LAN부터 입력 소유권·권위 물리·접속 손실·동기화 시험 |
