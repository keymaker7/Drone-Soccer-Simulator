# 드론축구 규정 근거와 구현 범위

확인일: 2026-10-26. 기본 프로필은 국내 5대5 훈련에 맞춘 **FIDA Class40**이다.
[공식 영문 PDF](https://dronesoccer.org/static/files/Rule-book-1.pdf)는
제5차 개정(2025-10-01),2026-01-01 시행이다.
[웹 규정](https://fidasystem.com/rules.html)은 조회에 사용하되 세부 조건은 PDF·대회 지침과 대조한다.

| 항목 | FIDA Class40 확인값 | 조항 |
|---|---|---|
| 권장 경기장 | 길이16m × 폭7m × 높이4.5m | 1-3 |
| 허용 범위 | 길이10~20m, 폭5~10m, 높이4~5m; 비율 약2:1 | 1-3 |
| 골대 | 내경60±1cm, 외경100±1cm, 중량10~15kg | 1-5 |
| 골대 위치 | 양 짧은 변 중앙에서 안쪽1.5m; 중심높이3~3.5m; 중앙을 향함 | 1-5 |
| 출발선·조종구역 | 출발점5개/선은 짧은 변에서1.5m; 외부 조종구역 폭2m | 1-2 |
| 기체 | 구형 외곽40±2cm, 비행중 총중량≤1100g, 개별 개구면적≤150cm² | 2-1 |
| 팀·포지션 | 팀당5명·최소3명; 스트라이커/가이드/리베로/스위퍼/키퍼 | 3-1 |
| 색 | 팀 빨강/파랑; 포지션 초록/분홍/하늘/노랑/흰색; 공격수·가이드 태그 | PDF 2-4/2-5 |

위 수치로 중심좌표를 잡으면 골대는 `(±6.5,0,3.0)m`이다. 높이3.0m는 허용범위에서
선택했다. 축방향 골대 두께0.16m는 시뮬레이터 선택이며 FIDA 의무규격으로 주장하지 않는다.
모터 추력·PID·관성·항력은 규정에서 제공하지 않는 별도 실측/튜닝 항목이다.

### 공식 원문 대조에 따른 설계 보완

PDF 인쇄9~10쪽의 태그 탈락 판정에는 상대의 식별 가능 조건이 있으며 추가 방향등은 역할색 조건이 있다.
사용자 요청의 엄격 무득점 정책과 현재 흰색/빨간색 훈련용 방향등은 별도 설정으로 명시할 계획이다.
현재 실행 파일이 이 구분을 구현한 것은 아니다. 부분 탈락의 자격은 대회 지침 확인 전 임의 확정하지 않는다.
이전 웹 요약 중심 설명과 차이가 있는 세부는 [정밀 검토](simulator-plan-review.md)에 기록했다.

득점은 스트라이커 기체 전체가 상대 골대를 앞→뒤로 통과해야 성립한다. 역방향은 무득점이며,
어느 방향이든 통과하면 팀 전체가 오프사이드가 된다. 전원이 자기 진영으로 복귀해야 해제된다.
자기 골대 역진입, 오프사이드 연속득점, 누적경고2회는 페널티 사유다. 경고는 세트간 유지되며
경기후 초기화한다. 페널티는 세트후 스트라이커-키퍼1대1, 5초다. 경기구조는 3분×3세트,
준비신호≥10초, 세트간 정비≥5분이다. 먼저2세트 승리 또는3세트후 더 많은 세트승으로 결정하며,
1승2무도 승리다. 필요시 연장·승부치기가 가능하다. [FIDA §§7~11](https://fidasystem.com/rules.html)

## FAI와 구분

[FAI 공식 안내](https://www.fai.org/page/sporting-rules-0)가 현재 연결하는
[2026 Version2 원문](https://www.fai.org/sites/default/files/2026-06/CIAM-F9-Drones-2026-06-01.pdf)은
2026-06-01 시행이다. 1월판보다 최신이며 조항명이 `F9A.*`로 바뀌었다.

FAI F9A-A는 권장14×7×5m(F9A.2.2, p30), 총중량≤1.2kg·외곽40+2cm(F9A.1.1, p28)이다.
골대 내경60cm·외경100cm·최대두께20cm, 안쪽1.5m 배치이며, 내경 하단높이2m이므로
중심은2.3m다(F9A.3, p32). 인원은3~5명이며 특정 국제시리즈3대3과 일반규정을 구별한다.
FAI F9A.1은 자동위치/경로보정 등을 금지하므로 SDACS 자율비행을 공식 경기적합으로 표시하지 않는다.
FIDA 프로필과 FAI 높이·중량을 혼합하지 않는다.

원문 PDF와 p28~32 렌더는 `Saved/Verification/rules-2026/`에 보관했다.
특히 `fai-v2-page-32.png`의 골대 단면도에서 내경·외경·축방향 두께를 직접 확인했다.

## 구현과 검증

`DroneSoccerRules.h/.cpp`는 엔진 독립 C++ 규칙 코어다. 기본은 Practice이며, Match는
Ready10초→Playing180초→Break300초→다음 Ready로 진행한다. Practice/Playing만 ARM을 허용한다.
세트 점수·승수·오프사이드·페널티 개수를 추적하며 최대3세트 또는2승에서 종료한다.
무승부는 그대로 보존한다. 비행 모드와 경기 단계는 별개이며 경기를 시작해도 자동 이륙하지 않는다.

기체 반경0.20m와 개구 반경0.30m를 고려해 중심의 여유는0.10m다. 코어는 축두께까지
기체 전체가 벗어난 후 득점하고, 통과중 중심이 여유 경계에 닿는 경우는 보수적으로 무효 처리한다.
오프사이드 해제도 전체 기체가 중앙선을 벗어나야 한다. `SetActive`는 공식 세트포기 등 외부
판정을 입력하는 용도다. 사람의 행위판정, 경고/카드, 페널티 경기 진행,
연장·승부치기·VAR은 미구현이며 완전한 심판 시스템으로 주장하지 않는다.

**가이드의 공격수 승계 — 규칙 코어만 구현(RUL-08 일부).** 득점 자격은 고정 ID(0·5) 대신 팀별
현재 공격수(`Striker(team)`·`IsStriker(id)`)로 판정한다. `ConfirmStrikerSuccession(team)`은
**심판 확인만** 기록한다. 공격수 불능 선언·조종 중지·가이드의 적법 접촉은 호출 전에 끝나야 하며,
단순 충돌로 호출하지 않는다. 승인 조건은 Practice/Playing 단계, 해당 팀의 원래 공격수가 아직 유지된 상태,
활성 가이드다. 두 번째 태그는 가이드만 달고 있으므로 세트당 한 번이다. 승계 전에 시작한 가이드의 골대 통과는
득점으로 이어지지 않고 새로 통과해야 한다. 승계된 원래 공격수는 득점·오프사이드를 만들지 않는다.
다음 세트와 `Reset`에서 원래 공격수로 돌아가는 것은 전체 기체 활성 복원과 같은 **시뮬레이터 선택**이며
FIDA 조항으로 확인한 것이 아니다. Unreal의 심판 입력·HUD·역할 띠/LED·AI 연동은 아직 연결하지 않았다.

`Tests/run-rules-tests.ps1`로 MSVC C++17 빌드 후 **57개 검사 통과**:
전체기체 통과, 반사/역진입, 포지션, 가장자리 접촉, 팀 전원복귀, 타이머·세트승·무승부,
큰 dt의 단계이월, 종료휘슬 시점 판정, 잘못된 입력과 초기화.

v0.7은 골대 질량을 실제 합계12.5kg으로 설정한다. §1-5의 안정된 설치·좌우 흔들림 금지를 반영하여 정규 경기는 물리 지지를 고정하고, 연습에서만 좌우 회전 없이 작은 앞뒤 충격 반응을 허용한다. 이 반응은 두 케이블의 정밀 탄성 해석이 아닌 제한된 진자 근사다. 골대 크기·질량과 달리 감쇠·마찰·관성 계수는 실측값이 아니다.

이동/회전한 골대의 실제 좌표계로 전체 기체 통과를 판정한다. 추가6개 규칙 시험은 평행 이동·회전·기울어진 골대의 통과와 무효 판정, 정지한 기체를 골대만 쓸고 지나가는 경우의 오득점 거부, 잘못된 좌표계 입력을 다룬다. 실제 Chaos 충돌·고정/감쇠 검사는 [v0.7 기록](releases/v0.7.0.md)과 구별한다.
