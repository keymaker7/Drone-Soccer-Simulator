## 적용 순서와 검수

1. **조종기 첫 사용**: 실제 장치 카드를 고르고 실제 배치에 맞게 Mode 1 또는 Mode 2를 선택하고 안내를 따른다. 단계별 현재 행동을 보여주고 수동 축/범위/프로필 도구는 고급 화면으로 옮긴다. 저장·USB 활성화·ARM은 명시적으로 분리한다. 연결 실패는 기존 상태 설명으로 이유를 표시한다.
2. **입력 품질**: 중립 흔들림·전체 범위·방향·중복 축을 실제 입력으로 확인한다. 스위치 배정·Expo·곡선 미리 보기는 별도 기능이며 이번 UI 변경에 구현됐다고 표시하지 않는다.
3. **훈련**: 이륙/착륙 → 일정 고도/방향 전환 → 골대 접근/통과 → 공격 후 복귀 → 수비/지원 → 고장·태그 탈락 판단. 과제마다 기록 조건과 성공 기준을 고정한다.
4. **복기**: 기존 F6는 시계열 JSONL이며 재생기가 아니다. 상태 녹화·사건·시각 이동·입력 그래프를 먼저 설계한 뒤 고스트/영상 내보내기를 추가한다. README GIF는 실행 장면 소개용이며 게임 내 리플레이 기능이 아니다.
5. **팀 경기**: 로컬 훈련과 LAN/온라인의 조종권·서버 판정·접속 복구를 분리한다. 레이싱 제품의 최대 접속 인원·FPV 기본값을 드론축구 5대5의 완료 근거로 가져오지 않는다.

본 프로젝트의 기본은 경기장 밖 **LOS·ANGLE 수동 조종**이다. 다른 제품의 FPV/Acro 중심 설계는 선택적 연습 기능을 검토하는 참고다. 제조사 모델·재질·로고·화면·매뉴얼 이미지는 복사하지 않는다.

세부 완료 기준은 [326개 기능 명세](simulator-feature-plan.md), 구현 순서는 [정밀 자체 검토](simulator-plan-review.md), 사용 방법은 [README](../README.md)를 따른다. 이 표의 기능을 참고 대상으로 등록한 것이 해당 기능의 구현 완료를 뜻하지 않는다.
