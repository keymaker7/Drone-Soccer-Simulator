# Class 40 기체와 경기장

## 최신 모델 해석 안내 — 2026-10-28

아래 2026-10-26 형상·정적 골대 설명은 초기 기록이다. 후속 보호구·내부 기자재는 [v0.6/v0.7 모델 기록](model-reference.md), 연습의 제한적 충돌 반응/공식 경기 고정 정책은 [최신 물리 설명](physics-models.md)을 함께 따른다. 보호 가드·내부 프레임의 독립 재설계는 [최신 계획](practice-candidates-2026-10-27.md#review-2026-10-28)의 C11 연결 과제로서 구현·권리 검토·물리 검증을 분리한다. 이 안내 추가는 모델 변경이나 실물 시험이 아니다.

2026-10-26 KST. 기본 규격은 [FIDA 2026 Class40](https://fidasystem.com/rules.html)이다. 외형은 [HELSEL STRIKER V3 공식 자료](model-reference.md)를 관찰하고 직접 작성한 참고형 절차적 모델이며 제조사 CAD·제품 인증·실측 디지털 트윈이 아니다.

기본 격자의 패널 계산은 `R²*Δ경도*(sin(위도2)-sin(위도1))`이다. R=19.65cm,Δ경도30°,위도0–30°에서101.0866cm²이며 봉 두께를 제외하기 전 값이다. 조밀한 추가 셀은 면적을 늘리지 않는다. 메시의 체결 강도·개구부 형상 인증이나 그물 얽힘을 검증한 것은 아니다.

보호구·LED는 Instanced Static Mesh 묶음으로 만든다. 루트 물리 구체 스케일0.4,일반 자식 위치2.5배 보정,인스턴스는 절대 스케일1의 cm좌표를 사용한다. 카본 결·바닥·콘크리트·고무의 자체 생성 질감과 Lumen 간접광·반사·가상 그림자를 적용했다. 소형20cm 기체는 현재 별도 모델로 제공하지 않는다. 크기만 줄인 물리를 소형 규격으로 부르지 않는다.

경기장은16×7×4.5m,네트10cm격자,양쪽 골대 내경60cm/외경100cm,끝에서1.5m 안쪽·중심높이3.0m다. 두 골대는 정적 강체이고 천장 케이블로 매단 형상이다. 골대 깊이16cm는 시뮬레이터의 선택값이다. 조종 구역은 양 끝 밖 폭2m이며 뒤 경계선을 표시한다. 규정과 심판 기능의 구현 한계는 [규정 기록](rules-sources-2026.md)을 참고한다.
